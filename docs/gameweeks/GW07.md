### Operational lessons

The initial official run failed due to an SSL handshake error reaching The Odds API while the VPN was disconnected.  With the VPN connected, the API became reachable and the official capture completed successfully.

The Odds API key appeared in the failed request traceback.  Rotate the exposed key, update local `.env`, and add credential-safe exception handling.  Never commit secrets.

The operational convention is one manual gameweek capture on Friday, with actual timestamps and lead hours preserved.  The earlier per-fixture freeze approach was superseded.
