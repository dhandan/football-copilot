## Pre-match diagnostics and registered questions

- **Agreement:** The champion and 40/60 shadow select the same 1X2 outcome in **9/10** fixtures.
- **Disagreement:** Chelsea vs Bournemouth. This is a prospective, pre-result test case for the model/market disagreement hypothesis, not proof of either model's superiority.
- **Modal scoreline concentration:** Model 2 produces `1-1` as its highest-probability individual scoreline in **7/10** fixtures; this is not the same as predicting a draw as the 1X2 argmax. Track under [xG/scoreline hypothesis #5](https://github.com/dhandan/football-copilot/issues/5).
- **Cold-start checks:** Ipswich, Hull City, Coventry City use the pre-existing promoted-team prior; no prior was changed for GW6. Track under [hypothesis #7](https://github.com/dhandan/football-copilot/issues/7).
- **Prospective challenger validation:** [Issue #2](https://github.com/dhandan/football-copilot/issues/2). Compare both forecasts using paired Accuracy, Log Loss, multiclass Brier and segment/sample diagnostics.
- **Market quality and source compatibility:** [Issue #3](https://github.com/dhandan/football-copilot/issues/3).

## Operational learning

The initial Odds API request failed during an SSL/TLS handshake. Enabling the VPN allowed the official market capture to succeed. For future Gameweeks **turn VPN on before running the market fetch**. This is an observed workaround rather than a confirmed technical root cause. Avoid copying API credentials or full credential-bearing request URLs into documentation.

### Diagnostics

- **Draws:** Three actual draws (Aston Villa vs Brentford; Man United vs Tottenham; Hull City vs Everton); neither champion nor shadow selected a draw. No evidence that classification-level draw discrimination has been solved.
- **Modal 1-1 concentration:** Seven of ten Model 2 modal scorelines were 1-1 versus only one actual 1-1. Model 2 hit zero exact scores. This remains a separate goal-model diagnostic from 1X2 probability performance.
- **Promoted-team cold starts:** Ipswich, Hull City and Coventry City: champion 0/3 correct; shadow also 0/3. Model 2 cold-start Log Loss **1.3177**, Brier **0.8337**. Small sample; do not infer a universal cold-start defect from three games.
- **Historical comparison:** GW6 Model 2 accuracy 30.0%, LL 1.1747 and Brier 0.7308 versus its published historical benchmarks of 52.69%, 0.9927 and 0.5927. These are different samples, not a formal same-cohort comparison.
- **Data quality incident:** Initial result ingestion stopped because Football-Data API listed already-played fixtures 560596 (Crystal Palace vs Nott'm Forest) and 560598 (Liverpool vs Man City) as `TIMED`. Later retries returned `FINISHED`; the final results file contains ten final results. The fetcher correctly refused to persist a partial results set.
- **Evaluation code defect:** The first shadow evaluation raised `Invalid ActualResult: Arsenal` because it used the human-readable team-name column rather than the H/D/A `ActualResultCode`. Fixed with version/code validation in [commit `3a5c546`](https://github.com/dhandan/football-copilot/commit/3a5c546653ef7900c9597774294bc4f10aab1546); rerun succeeded. Frozen predictions were untouched.

## First prospective test decision and sprint retrospective

**Decision: Retain `Model2_v1.0` as production champion; continue `Model2_OpeningMarket_40_60_v1.0` as frozen shadow.** Do not retrospectively retune or promote on a single 10-match Gameweek. GW1–GW5 blend results were **development/selection evidence**, not an independent extension of the 10-match prospective trial.

What worked: sealed forecasts and consistent fixture IDs; market blend improved all three overall GW6 metrics; the results-ingestion guard rejected non-final statuses; both assessments are now committed with reproducible fixture-level outputs.

What failed or remains unresolved: slow/partial upstream status updates, evaluator schema mismatch (now fixed), no predicted draws, modal 1-1 concentration, and cold-start misclassifications. Historical opening-odds comparisons also remain source/timing-different from the live Odds API captures.

**Next sprint under the [accelerated experiment policy](../accelerated-experimentation.md):** Pursue limited, evidence-led historical draw/xG/cold-start diagnostics without repeating rejected calibration variants. Develop new challengers in parallel only if historically justified; register each version before future kickoff. Continue collecting identical-fixture prospective evidence on the existing frozen shadow and review every 2–3 Gameweeks. No automatic promotion at a fixed Gameweek; minimum evidence, sequential monitoring and multiple-comparison safeguards must be specified prospectively.

Track actions in [programme #1](https://github.com/dhandan/football-copilot/issues/1), [validation #2](https://github.com/dhandan/football-copilot/issues/2), [market quality #3](https://github.com/dhandan/football-copilot/issues/3), and [operational controls #8](https://github.com/dhandan/football-copilot/issues/8).
